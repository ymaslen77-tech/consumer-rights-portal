# Права потребителя — независимый юридический портал РФ

**Статус:** этап 1, исходный автономный прототип на базе архитектурных принципов ДГИ. Не опубликован. Исходники загружены в отдельный GitHub-репозиторий `ymaslen77-tech/consumer-rights-portal` в ветку `feature/consumer-rights-initial`; Coolify-приложение для него пока не создано. Это **не буквальный клон всего исходного репозитория ДГИ**, а безопасная независимая стартовая кодовая база, предназначенная для переноса в отдельный репозиторий.

## Что сделано

- Next.js 16 + React 19 + TypeScript, адаптивный дизайн, metadata, закрытый до релиза robots/sitemap.
- 20 правовых разделов, 60 базовых ситуаций с шагами, перелинковкой и первоисточниками.
- 8 целевых страниц органов / общественных объединений / консультационных служб.
- 10 черновых документов с клиентской формой, предварительным просмотром и экспортом в текст (без отправки данных).
- 6 реестровых официальных первоисточников, из них приоритетные: Роспотребнадзор, его ГИС, портал Москвы.
- Контакты центрального аппарата, федеральной линии и московского управления подтверждены официальными публикациями на 30.10.2026.
- Новостная линия (0 записей до проверки) и указатель нормативных источников, без ложных утверждений об актуальности редакций.
- Отдельная страница будущей судебной практики: **0 проверенных актов, никаких выдуманных исходов/PDF**.
- Контентный тест, базовый CI и Dockerfile Coolify.

## Ограничения

- Полный закон, точные сроки, формулы взысканий, права на индивидуальное требование требуют точной сверки действующих редакций. 60 ситуаций пока содержат *безопасные вводные алгоритмы*, а не юридически проверенные разборы всех исключений.
- Нет серверной CMS, PostgreSQL runtime, авторизации или пользовательских кабинетов; эти слои переносим из эталонного монорепозитория отдельным этапом после создания нового GitHub-репозитория и базы.
- Адрес `prav.mos.ru` подтверждён по официальным сообщениям, но прямое получение страниц в момент проверки не получилось. На его содержание не выдаём фиктивной глубокой проверки.
- Контактный справочник всех регионов не заполнен вымышленными телефонами: есть официальный указатель территориальных органов.
- Документы — не отправляются органам и не являются заверенными юридическими документами.
- В прототипе отсутствуют новости и проверенные судебные акты. Их источники и пайплайн будут созданы отдельно.

## Локальный запуск

Node.js 22+, pnpm 10 и доступ к реестру пакетов. При первом запуске сформируйте lockfile и закоммитьте его в новом репозитории, после чего замените install в CI и Dockerfile на `--frozen-lockfile`:

```bash
npm install -g pnpm@10.0.0
pnpm install
pnpm test
pnpm typecheck
pnpm build
pnpm dev
```

Локально: http://localhost:3000. Не включайте индексацию без отдельного HTTPS-домена, проверки и письменного решения владельца.

## Следующие этапы (обязательно отдельно от ДГИ)

1. **Репозиторий и ветки созданы, исходники импортированы.** Настроить ruleset `infra/coolify-russian-vps`, обязательные PR checks, CODEOWNERS и исключить прямой push; до настройки защиты не объединять PR.
2. Зафиксировать пакеты точным lockfile; запустить CI и локальную сборку.
3. Перенести из ДГИ изолированные приложения `apps/cms`, PostgreSQL и безопасные генераторы PDF **без его старых данных и рабочих секретов**; настроить новое имя workspace и проверки.
4. Разработать полные тематические маршруты с действующими нормативными источниками, таблицами документов, судебными адаптерами (не только 2kas) и новостями.
5. Создать новое Coolify-приложение и БД на российском VPS; отдельные DNS/HTTPS/секреты/бэкапы. Ручной Deploy после CI и документированной приёмки.
6. Проверить все маршруты и контакты по HTTP. Только затем включать `SITE_CUTOVER=true`, `SITE_RELEASE_APPROVED=yes` и реальный `SITE_URL`.
