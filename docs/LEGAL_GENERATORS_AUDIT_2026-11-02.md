# Юридическая и техническая приёмка генераторов (02.11.2026)

## Метод
Приоритет: действующая редакция официального нормативного акта; затем официальные разъяснения органов и судебные акты; затем КонсультантПлюс/Гарант как проверенные справочные источники. Не устанавливать применимость к конкретному потребителю только потому, что два пересказа совпадают. Для спорных норм сверять даты действия, условия и пределы.

## Уровни приёмки

1. REFERENCE_CHECKED: номера, статьи и источники в реестре проверены.
2. CASE_CONDITIONAL: для каждого из 60 маршрутов существует отдельная карта статей, предупреждение о применимости и выбор конкретного документа. Проверку фактических обстоятельств пользователь подтверждает самостоятельно.
3. DOCUMENT_TECH_TESTED: для каждого сочетания ситуация × документ создаётся текст и DOCX; GUI в Chromium формирует DOCX после заполнения полей и позволяет печатать PDF.
4. READY_TO_FILE: не присваивается автоматически. Требуются данные заявителя, адресата, исполнение процессуальных условий, правильные суммы и полный комплект приложений.

## Известные ограничения

Юридическая корректность всех 60 вариантов не тождественна утверждению правомерности всех возможных требований пользователя. По 43 ранее выделенным маршрутам сохраняются условия применения специальных отраслевых актов к конкретному событию; метки сверенной библиографии не подменяют проверку содержания по фактам.
Штрафы, неустойки и пошлины не вычисляются без данных. Для судебного иска проверка ст. 131–132 ГПК РФ необходима даже если DOCX/HTML технически корректен.
