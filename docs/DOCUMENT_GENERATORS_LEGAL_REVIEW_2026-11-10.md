# Правовая и техническая сверка генераторов — 10.11.2026

## Найденные ошибки

1. Один и тот же текст поля адресата «Продавец, исполнитель или иное обязанное лицо» применялся к ЖКХ, банкам, ведомствам и другим обращениям. Исправлено: генератор теперь использует конкретного адресата соответствующего шаблона. Для коммунальных услуг дополнительно проверяется исполнитель по договору, а не автоматически назначается УК.
2. В ситуации поле «ПРАВОВЫЕ ОСНОВАНИЯ» заменялось названиями ссылок из справочного индекса, а не содержанием правовых оснований шаблона. Исправлено для всех документов: справочные ссылки остаются на сайте, нормативное обоснование берётся из индивидуального `legalBasis`, уточнённого по действующим источникам.
3. Незаполненные необязательные поля в черновике могли отображаться в квадратных скобках. Такие поля теперь не выводятся в формальный документ.

## Пример ТКО

Документ по факту невывоза ТКО опирается на [части 4, 5 статьи 157 ЖК РФ](https://www.consultant.ru/document/cons_doc_LAW_51057/ec5cb28b6c8828f0e1ecd4adb41f9d3ba2fefa39/), [статью 157.2 ЖК РФ](https://www.consultant.ru/document/cons_doc_LAW_51057/7624039a28c468fd7d20a0ea1a8f0ac705f95e49/) для прямых договоров, [пункты 106, 109 Правил № 354](https://www.consultant.ru/document/cons_doc_LAW_114247/1dc2ccc34653658a6d4ab1c18f42c5cf0ab5b46a/) (регистрация обращения, проверка и акт), [пункты 148(45)–148(49)](https://www.consultant.ru/document/cons_doc_LAW_114247/f608f710b118e5cf596aab34500c1a64c0c67a44/) (услуга по ТКО). Обязанное лицо определяется по договору: это может быть УК/ТСЖ или региональный оператор, и нельзя считать УК единственным адресатом.

## Что подтверждают тесты

Общее количество шаблонов: **46**. Маршрутов: **101**. Сочетаний: **199**. Автоматические проверки подтверждают разбор данных, доступность ссылок в карте, предметный адресат, присутствие нормативных оснований в тексте, создание DOCX/печать PDF, отсутствие служебных комментариев и сохранение запрета индексации.

**Это не юридическое заключение о пригодности каждого документа к подаче.** Автоматический генератор не устанавливает суд, надлежащего ответчика, страховые исключения, допустимость конкретной неустойки, доказанность недостатка, сроки и прочие индивидуальные обстоятельства. Перед направлением документа требуется проверить эти вопросы по актуальному тексту закона и доказательствам.

Один универсальный шаблон может применяться к нескольким разным ситуациям. Если материальное право различается, важны выбранная ситуация и специальная правовая квалификация; в остальных случаях составлено осторожное обоснование без обещания результата.
